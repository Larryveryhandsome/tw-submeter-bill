# tw-submeter-bill｜分租電費計算

分租套房、雅房，每間裝了分表（小電表），每兩個月抄一次表、算一次電費，常常算到頭昏：
誰用了幾度、公共用電怎麼分、四捨五入差的那幾塊錢算誰的？這個網頁會：

- **記住每間房、每一期的抄表**：開新一期時，上期的「本期度數」自動帶成這期的「上期度數」
- **兩種算法**：固定每度單價（例如 5 元／度），或**依台電帳單比例分攤**（帳單金額 ÷ 總度數 × 每間度數）
- **公共用電**（走廊燈、熱水器、抽水馬達……＝台電總度數 − 各分表合計）可以平均分、依用電比例分，或由房東負擔
- **自動提醒**：度數變負數（換表或抄錯）、比上期暴增、漏抄
- **換電表**也算得出來：填舊表最後度數和新表起始度數就好
- 產生**繳費通知單**（A4 一頁兩張）和**總表**，可直接列印或存 PDF

免安裝、免伺服器、不連網：雙擊 `index.html` 就能用。資料只存在你這台電腦的瀏覽器。

線上試用（示範資料）：https://larryveryhandsome.github.io/tw-submeter-bill/

## 5 分鐘開始

1. 下載這個專案（綠色 **Code** 按鈕 → **Download ZIP**），解壓縮。
2. 雙擊 **`index.html`**。一開始會顯示**示範資料（房客、電表編號、度數、金額全部是假的）**，可以先玩看看。
3. 展開最下面的「**房間設定**」，改成你自己的房間：樓層、房號、電表編號、房客。空房取消勾選「計費」。
4. 按「**開新的一期**」，填本次抄表日、台電帳單金額與總度數，再把每間的「本期度數」填上。
5. 看總表和通知單沒問題，按 **列印繳費通知單**（或存 PDF 傳給房客）。

### 用 Excel 抄表再匯入

1. 打開 **`data/readings.example.csv`**（可用 Excel 開），照「電表編號」填本期度數。
2. 用「另存新檔 → **CSV UTF-8（逗號分隔）**」存檔。
3. 網頁展開「資料備份與匯入匯出」→「**匯入抄表 CSV**」，會套進目前這一期。
   「上期度數」欄空白時會保留網頁上原本的值；沒有「電表編號」欄時改用「房號」對。

### 換電表怎麼填

在那間房勾「**換表**」，填：

- **舊表最後度數**：拆下來的舊表最後看到的數字
- **新表起始度數**：新表裝上時的數字（通常是 0）
- **本期度數**：抄表當天新表的數字

用電度數 =（舊表最後 − 上期）+（本期 − 新表起始）。下一期會自動從新表的度數接著算。

### 備份

資料存在瀏覽器裡，**換電腦、清除瀏覽器資料、用私密視窗都會不見**。
請定期按「**匯出備份（JSON）**」，要還原時用「匯入備份」。「匯出本期 CSV」可以用 Excel 開（有 BOM，不會亂碼）。

## 設定（`config.js`）

用記事本打開 `config.js`。網頁上「計費設定」改過的值會存在瀏覽器、優先於這裡；按「恢復 config.js 預設」可還原。

| 設定 | 說明 |
|---|---|
| `title` | 網頁、總表和通知單的標題 |
| `landlord`、`contact` | 通知單上的出租人稱呼與電話 |
| `mode` | `ratio` 依台電帳單比例分攤；`fixed` 固定每度單價 |
| `unitPrice` | `fixed` 模式每度幾元 |
| `commonMode` | 公共用電：`equal` 計費房間平均分；`usage` 依用電比例分；`landlord` 房東負擔 |
| `rounding` | `round` 四捨五入到元；`ceil` 無條件進位；`floor` 無條件捨去；`none` 不取整（小數 2 位） |
| `remainder` | 取整後的差額：`last` 加到最後一間（合計＝原始總額四捨五入，通常剛好等於帳單）；`landlord` 由房東吸收 |
| `minCharge` | 每間最低收費（元），`0` 代表不設 |
| `spikeFactor`、`spikeMinKwh` | 本期度數超過上期幾倍、且至少多幾度，就提醒「暴增」 |
| `noticeNote` | 通知單下方的說明文字 |
| `fields` | 抄表 CSV 的欄位名稱 |

## 計算方式

1. **每間用電度數** = 本期度數 − 上期度數（換表時見上面公式）。
   度數缺漏或變負數的房間**不收費、不參與分攤**，會列在提醒裡，請先修正。
2. **公共用電** = 台電帳單總度數 − 各計費房間度數合計（沒填總度數就不算公共用電；算出負數視為 0 並提醒，通常是抄表日和帳單期間對不上）。
3. **每度單價**：固定模式用設定的單價；比例模式 = 台電帳單金額 ÷ 台電總度數。
4. **每間應繳** =（自己的度數 + 分到的公共用電度數）× 每度單價，再依設定取整、加最低收費。

### 例子（依台電帳單比例、公共用電平均分）

台電帳單 **2,400 元／480 度**，每度 2,400 ÷ 480 = **5 元**。四間房分表：

| 房間 | 用電度數 | 分到公共用電 | 計費度數 | 應繳 |
|---|---:|---:|---:|---:|
| A | 120 | 15 | 135 | 675 |
| B | 90 | 15 | 105 | 525 |
| C | 150 | 15 | 165 | 825 |
| D | 60 | 15 | 75 | 375 |
| 合計 | 420 | 60 | 480 | **2,400** |

公共用電 = 480 − 420 = 60 度，平均每間 15 度。四間合計剛好等於台電帳單。

如果改成「依用電比例分」，每間就是 **自己度數 ÷ 分表合計 × 帳單金額**；改成「房東負擔」，每間只付自己度數 × 5 元，公共的 60 度（300 元）由房東吸收。

**取整差額**：例如 1,000 元三間平分，每間 333.33 元，四捨五入是 333、333、333，少 1 元。
選「加到最後一間」→ 333、333、334（合計 1,000）；選「由房東吸收」→ 三間都 333，房東負擔 1 元。

## 法規與注意事項

- 電費分攤原則上依《民法》及雙方租約約定；建議在租約寫清楚計費方式、公共用電怎麼分、抄表日。
- 台電住宅用電若為累進費率，用越多每度越貴，以「台電帳單比例分攤」原則上較能反映實際成本、也較公平。
- 房東自行訂每度單價時，原則上不得高於相關規定的上限。內政部「住宅租賃契約書範本」及相關應約定事項對電費計收有約定方式，各地方政府也可能另有規定，請以最新公告為準。
- 計算結果原則上僅供參考，實際應繳金額以租約與台電帳單為準。
